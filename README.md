# Tata Group Data Visualisation Virtual Experience

## 1. Project Overview
This repository contains my submission for the Tata Group Data Visualisation simulation on Forage. I acted as a Data Consultant to provide the CEO and CMO of a retail business with data-driven insights to support their global expansion strategy.

## 2. Key Objectives
* **Business Strategy:** Framing strategic questions relevant to C-suite executives (CEO & CMO).
* **Data Quality:** Cleaning a large retail dataset to ensure accuracy in reporting.
* **Analysis & Visualisation:** Creating modular analytical reports to identify sales trends and market demand.

---

## 3. Project Structure

### [Task 1: Business Questions & Strategy](./Business_Questions_Strategy.md)
This file contains 8 strategic questions (4 for the CEO and 4 for the CMO) designed to guide the data exploration process.
* **Focus:** Revenue momentum, product risk, customer retention, and market basket analysis.

### [Task 2: Data Analysis & Visualisation](./Data_Analysis_and_Visualisation.md)
This file details the technical execution using **Power BI**. 
* **Data Cleaning:** Process of removing returns (negative quantities) and invalid unit prices.
* **Analytical Reports:** Breakdown of the 4 key visuals created to answer the executive requirements.

## 5. Tools & Technologies
* **Power BI:** Data modeling and Visualisations.
* **Excel / Power Query:** ETL (Extract, Transform, Load) and data cleaning.
* **Markdown:** Project documentation and storytelling.

## 6. Key Learnings
* Understanding how to clean "bad data" using conditional logic.
* Differentiating between CEO-level (Operations) and CMO-level (Marketing) data needs.
* Organizing complex analysis into a structured, multi-tab workbook for better clarity.
